# Portfólio — Engenharia de Dados

Site pessoal com meus projetos de Engenharia de Dados, hospedado gratuitamente no **GitHub Pages**.

🔗 **Acesse:** https://salma-barbosa-data-engineer.github.io

## Stack
- HTML, CSS e JavaScript puro (sem framework, sem build)
- Hospedagem: GitHub Pages

## Como atualizar
Todos os projetos e skills ficam no final do `index.html`, nas listas `PROJECTS` e `SKILLS`.
Para adicionar um projeto, copie um bloco `{ ... }`, edite os campos e faça commit.
O site atualiza sozinho em cerca de 1 minuto.
